## What the theme brings

<CardGrid>
  <Card title="Config" icon="setting">`defineDocs` writes the Astro config: base path, math, API reference, link check.</Card>
  <Card title="Look" icon="star">The paper/ink palette with a teal accent, a header with section links, and this header picture, drawn anew for each site.</Card>
  <Card title="Notebooks" icon="open-book">`starlight-notebooks` executes notebooks and turns them into pages.</Card>
  <Card title="Gallery" icon="seti:image">`starlight-gallery` runs example scripts and shows their figures in a grid.</Card>
</CardGrid>

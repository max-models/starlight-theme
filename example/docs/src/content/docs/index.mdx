A project's `docs/astro.config.mjs` names the project and its pages, and `defineDocs` writes the
rest: the base path, KaTeX math with the project's macros, the API reference from the docstrings,
the link check, and this look, the same for every max-models site.

```js
import { defineDocs } from '@max-models/starlight-theme';

export default defineDocs({
	repo: 'example',
	title: 'example',
	pythonPackage: 'example_pkg',
	nav: [{ label: 'Tutorials', link: '/tutorials/', description: 'Notebooks, run in CI.' }],
});
```

Notebooks in `tutorials/` and scripts in `examples/` are run when the docs are built and turned into
pages (`starlight-notebooks`, `starlight-gallery`), so every figure on the site comes from the code
as it is.
